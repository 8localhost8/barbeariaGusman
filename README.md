# Barbearia Gusman

Landing page demonstrativa em HTML, CSS e JavaScript puro, baseada no template anterior.

Abra `index.html` ou execute `python -m http.server 8765 --bind 127.0.0.1` nesta pasta.

- Atendimento somente com hora marcada, sem grade fixa de horários.
- Modo demonstração ativo: agendamento e telefone exibem o aviso de ativação após a compra.
- Nome, endereço, telefone, cinco imagens e avaliações conforme material fornecido.
- Entrada, banheiro e estacionamento acessíveis para pessoas em cadeira de rodas.
- Serviços no array `SERVICES` de `script.js` são opções de exemplo editáveis.
- Facebook omitido por solicitação do proprietário do projeto.
- Fotos originais em `Fotos/` e versões otimizadas em `Fotos/web/`.
